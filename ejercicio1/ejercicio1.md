## Ejercicio 1. Selectores

Crea una página web como la imagen. En esta ocasión el titular es un bloque div cuyo atributo class es **title** mientras que las líneas restantes son párrafos con atributo class **line**. 
Especificaciones para el título:
- Tamaño de la fuente 24px;
- Fuente: Arial, sans-serif
- Centrado
- Azul

Especificaciones de las líneas:
- Fuente arial, sans-serif
- Color rojo
- Margen izquierdo 80px
- Define las reglas CSS para estos selectores
